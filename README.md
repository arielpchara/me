# Ariel Pchara - Personal Website

![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Deployed-brightgreen)

A modern, minimalist personal website showcasing my professional experience as a Senior Fullstack Engineer | React & Node.js Specialist | TypeScript, Microservices, AWS.

## 🚀 Features

- Clean, minimalist design with dark gradient theme
- Responsive layout that works on all devices
- Professional summary and detailed skills categorization
- Interactive UI elements with subtle animations
- Accessibility-focused development
- Optimized for performance

## 💻 Technologies

- React, TypeScript and React Router
- Vite, with every route prerendered to static HTML
- Posts and profile content in Markdown (`content/`)
- Remix Icons, Inter and JetBrains Mono

## 📋 Sections

- About Me - Professional background and summary
- Skills - Categorized by:
  - Languages
  - Frontend
  - Backend & DevOps
  - Tools & Others
- Contact - Links to email and social profiles

## 🛠️ Setup

1. Clone the repository
```bash
git clone https://github.com/arielpchara/me.git
cd me
```

2. Install and run
```bash
npm install
npm run dev
```

The site runs at http://localhost:4173. `npm run build` creates the static site in `dist/`.

## 📤 Deployment

The site is deployed using GitHub Pages and is available at:

- [pchara.com](https://pchara.com)

Every push to `main` builds the site and deploys it with GitHub Actions (`.github/workflows/deploy.yml`).

### Deploying your own version:

1. Fork this repository
2. In the repository settings, set Pages > Source to **GitHub Actions**
3. (Optional) Put your domain in `public/CNAME`

## 🔄 Updates

To add a post, create a Markdown file in `content/posts/` and push to `main`. See `AGENTS.md` for the format.
